💡 Was ist die Interactions API?

Im Gegensatz zur klassischen generate_content API ist die Interactions API speziell für autonome Agenten wie Antigravity konzipiert:

  • Zustandsbehaftet: Über previous_interaction_id merkt sich der Agent den Session-Kontext.
  • Denkprozesse: Gedanken & Arbeitsphasen werden separat als ThoughtStep geliefert.
  • API-Version: Läuft über v1beta mit environment={'type': 'remote'}.

🎓 Google Interactions API & Antigravity Crashkurs

Die Interactions API (Google GenAI SDK v3.0.0+ / REST v1beta) ist Google's nächste Generation für komplexe, zustandsbehaftete Agenten-Workflows.

1. Warum "agent" statt "model"?

Das Modell antigravity-preview-latest ist als autonomer Agent klassifiziert. Wenn man es über client.models.generate_content(...) oder mit model='antigravity-preview-latest' anfragt, meldet die API: "refers to an agent, please use the 'agent' field instead".

2. Die benötigte SDK-Initialisierung

from google import genai

client = genai.Client(
    api_key="DEIN_KEY",
    http_options={"api_version": "v1beta"}  # WICHTIG!
)

3. Stateful Multi-Turn

Um Konversationen fortzuführen, musst du nicht den gesamten Chat-Verlauf erneut mitsenden! Übergib einfach die ID der letzten Antwort als previous_interaction_id: 

# 1. Turn
res1 = client.interactions.create(
    agent="antigravity-preview-latest",
    environment={"type": "remote"},
    input="Merke dir: Mein Codename ist Nighthawk."
)

# 2. Turn (Agent erinnert sich!)
res2 = client.interactions.create(
    agent="antigravity-preview-latest",
    environment={"type": "remote"},
    previous_interaction_id=res1.id,
    input="Wie lautet mein Codename?"
)

4. Denkprozesse (Thought Steps)

Antigravity gibt getrennte Schritte (steps) zurück. Ein Schritt vom Typ thought enthält die interne Überlegung der KI, während model_output die finale Antwort an den Nutzer darstellt.
